Products API

Endpoints for listing, creating, updating, and removing products. All request and response bodies are JSON.

Base URL https://api.xime.com/v1

Authentication

Every endpoint on this page requires authentication. Requests without valid credentials receive a 401 Unauthorized response.

AUTH

HTTP Basic Authentication

Send credentials in the Authorization header on every request, base64-encoded as username:password.

Authorization: Basic bGVhZjpwcm9kdWN0LWtleQ==
GET /products Get all products

Returns a list of products. Use the query parameters below to filter by category or control how many results come back.

Query Parameters

NameTypeDescription
categorystringFilter the products by category. optional
limitintegerThe number of products per page. optional

cURL

curl -u "user:password" \
  "https://api.xime.com/v1/products?category=footwear&limit=20"

Responses

200A list of products.
401Unauthorized.
500Internal Server Error.
POST /products Create a new product

Creates a product from the fields below and returns the newly created record.

Request Body — ProductInput

FieldTypeRequired
namestringrequired
descriptionstringrequired
pricenumberrequired
categorystringrequired

cURL

curl -u "user:password" \
  -X POST "https://api.xime.com/v1/products" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Trail Runner 2",
    "description": "Lightweight trail running shoe",
    "price": 129.99,
    "category": "footwear"
  }'

Responses

201Product created successfully.→ Product
400Bad Request.
401Unauthorized.
500Internal Server Error.
